# Contributing to KubeVirt Datamover Plugin

This project is part of the OADP (OpenShift API for Data Protection) ecosystem.

## Guidelines

Contributing guidelines for this project are the same as the main OADP Operator project:

- **Contributing Guide**: [OADP Operator Contributing](https://github.com/openshift/oadp-operator/blob/oadp-dev/docs/CONTRIBUTING.md)
- **Code of Conduct**: [OADP Operator Code of Conduct](https://github.com/openshift/oadp-operator/blob/oadp-dev/CODE_OF_CONDUCT.md)

## Quick Start

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests: `make test`
5. Submit a pull request

## Building

```bash
# Build locally
make build-local

# Build container image
make container

# Run tests
make test
```

## Questions?

For questions or discussions, please open an issue or reach out via the OADP community channels.
